# Storage Monitor
![test](https://github.com/KoheiEbara0210/storage-monitor/actions/workflows/test.yml/badge.svg)

自分のストレージの使用量を確認する
最初にCドライブかDドライブのどちらを確認するか選択する
CドライブならCをDドライブならDを入力することで選択できる
選択したストレージの使用量を単位Bで表示する

## 必要なソフトウェア
- Python
  - テスト済みバージョン: 3.10〜3.14

## テスト環境
- Ubuntu 24.04 LTS
